# 图书管理系统代码解析

## 一、总体结构图

```bash
程序入口 if __name__ == "__main__"
   └── LibrarySystem 对象
        ├── books: dict[str, Book]          # 所有图书
        ├── members: dict[str, Member]      # 所有会员
        ├── current_member: Member | None   # 当前登录会员
        │
        ├── 数据加载/保存
        │    ├── _load_data()
        │    │    ├── _load_books()   -> 读 books.json  -> 创建 Book
        │    │    └── _load_members() -> 读 members.json -> 创建 Member
        │    └── _save_data()
        │         ├── _save_books()
        │         └── _save_members()
        │
        ├── 登录
        │    └── login()
        │
        └── 主循环 run()
             ├── borrow_book()        借书
             ├── return_book()        还书
             ├── show_borrowed_books() 查看已借
             └── 退出
```


**类之间的关系：**


```bash
Book                 # 独立实体，表示一本书

Member(ABC)          # 抽象会员
 ├── NormalMember    # 普通会员
 └── VIPMember       # VIP会员

LibrarySystem        # 系统控制器
 ├── 持有多个 Book
 ├── 持有多个 Member
 └── 持有 current_member
```


>Book 管库存，Member 管借阅规则，LibrarySystem 管交互、登录、数据读写。



## 二、分层看代码

### 1. 模型层：数据实体
**Book：图书实体**


**职责：**
- 保存图书编号、标题、作者、总数、可用数量。
- 负责“借出一本”和“归还一本”的库存变化。
- 负责把自己转成 JSON 字典。

**关键方法：**

| 方法                 | 作用 |
|--------------------|  - |
| `borrow_book()`      | 可用数量减 1，失败返回 False |
| `return_book()`      | 可用数量加 1 |
| `get_available_num()` | 获取当前可借数量 |
| `to_dict()`          |	序列化为 JSON 需要的字典|


>它不关心“谁借了书”，只关心“我还有没有库存”。

<br>

**Member(ABC)：会员抽象基类**

职责：

- 保存会员编号、姓名、密码、已借图书列表。
- 实现通用的借书、还书逻辑。
- 规定子类必须实现 `get_max_books()`。

关键方法：

| 方法                   | 作用                                   |
| :--------------------- | :------------------------------------- |
| `borrow_book(book)`    | 检查重复、检查上限、检查库存，然后借书 |
| `return_book(book)`    | 从借阅列表移除，并让图书库存 +1        |
| `get_max_books()`      | 抽象方法，子类必须实现                 |
| `get_password()`       | 返回密码                               |
| `get_borrowed_books()` | 返回借阅列表副本                       |
| `to_dict()`            | 序列化会员信息                         |

它不关心“书怎么存”，只关心“我这个会员能借几本、已经借了哪些”。

`NormalMember` 和 `VIPMember`

```
NormalMember：最大可借 = 3
VIPMember：最大可借 = 6 + vip_level
```

它们只做一件事：**实现 `get_max_books()`**。
这就是抽象类的作用：强制所有会员子类都必须遵守同一个规则。





### 2. 控制层：`LibrarySystem`

这是整个程序的“大脑”。

职责：

- 加载数据。
- 保存数据。
- 处理登录。
- 显示菜单。
- 调用会员的借书/还书方法。
- 操作完成后写回 JSON。

关键属性：

| 属性                  | 含义                             |
| :-------------------- | :------------------------------- |
| `self.books`          | 字典：`book_id -> Book 对象`     |
| `self.members`        | 字典：`member_id -> Member 对象` |
| `self.current_member` | 当前登录的会员                   |

关键方法：

| 方法                    | 作用                                                 |
| :---------------------- | :--------------------------------------------------- |
| `_load_data()`          | 启动时加载图书和会员                                 |
| `_load_books()`         | 读 `books.json`，创建 `Book`                         |
| `_load_members()`       | 读 `members.json`，创建 `NormalMember` / `VIPMember` |
| `_save_data()`          | 保存全部数据                                         |
| `login()`               | 登录，设置 `current_member`                          |
| `borrow_book()`         | 借书菜单逻辑                                         |
| `return_book()`         | 还书菜单逻辑                                         |
| `show_borrowed_books()` | 查看当前会员已借图书                                 |
| `run()`                 | 主循环，分发菜单选择                                 |

------

### 3. 入口层



```python
if __name__ == "__main__":
    try:
        LibrarySystem().run()
    except FileNotFoundError as e:
        print(f"[错误] {e}")
```



流程很简单：

```text
创建 LibrarySystem
   -> 自动加载数据
   -> 调用 run()
   -> 登录
   -> 进入菜单循环
```



------

### 4. 数据层：JSON 文件

text

```
data/
 ├── books.json
 └── members.json
```



`books.json` 存图书信息，例如：

```json
[
  { "编号": "B001", "标题": "Python编程", "作者": "张三", "数量": 5, "可用数量": 4 }
]
```



`members.json` 存会员信息，例如：

```json
[
  { "卡号": "N001", "姓名": "小明", "密码": "123456", "借阅": ["B001"] },
  { "卡号": "V001", "姓名": "小红", "密码": "123456", "会员等级": 2, "借阅": [] }
]
```



注意：
会员的 `借阅` 里存的是 **book_id 字符串**，加载时再通过 `self.books[bid]` 还原成 `Book` 对象。

## 三、运行时核心流程

### 1. 启动初始化

```text
main
 └── LibrarySystem()
      └── _load_data()
           ├── _load_books()
           │    └── books.json -> Book 对象 -> self.books
           └── _load_members()
                └── members.json -> NormalMember/VIPMember -> self.members
```



------

### 2. 登录



```text
run()
 └── login()
      ├── 输入卡号
      ├── 在 self.members 中查找
      ├── 校验密码
      └── 设置 self.current_member
```



------

### 3. 借书流程

```text
borrow_book()
 ├── _show_books()                  显示所有图书
 ├── 输入 book_id
 ├── 从 self.books 取出 Book
 └── self.current_member.borrow_book(book)
      ├── 检查是否已借过同一本书
      ├── 检查是否达到 get_max_books()
      ├── 调用 book.borrow_book() 减少库存
      ├── 加入 borrowed_books
      └── 返回成功/失败
 └── 如果成功，_save_data() 写回 JSON
```



调用链：

```text
LibrarySystem.borrow_book
   -> Member.borrow_book
        -> Member.get_max_books
        -> Book.borrow_book
        -> Member.__borrowed_books.append
   -> LibrarySystem._save_data
```



------

### 4. 还书流程



```text
return_book()
 ├── show_borrowed_books()          显示当前会员已借图书
 ├── 输入 book_id
 ├── 从 self.books 取出 Book
 └── self.current_member.return_book(book)
      ├── 在 borrowed_books 中按 book_id 查找
      ├── 从借阅列表移除
      ├── 调用 book.return_book() 增加库存
      └── 返回成功/失败
 └── 如果成功，_save_data() 写回 JSON
```



调用链：



```text
LibrarySystem.return_book
   -> Member.return_book
        -> 查找已借图书
        -> Book.return_book
        -> 从 borrowed_books 移除
   -> LibrarySystem._save_data
```



------

### 5. 查看已借图书



```text
show_borrowed_books()
 └── current_member.get_borrowed_books()
      └── 遍历打印
```



------

### 6. 主循环



```text
run()
 ├── login()
 └── while True:
      ├── 显示菜单
      ├── 输入 choice
      ├── 1 -> borrow_book()
      ├── 2 -> return_book()
      ├── 3 -> show_borrowed_books()
      ├── 4 -> break
      └── 其他 -> 提示无效
```

## 四、代码里的关键设计思想

| 设计点     | 体现                                                         |
| :--------- | :----------------------------------------------------------- |
| 抽象类     | `Member(ABC)` + `@abstractmethod get_max_books()`            |
| 继承       | `NormalMember`、`VIPMember` 继承 `Member`                    |
| 封装       | `Book.__available_num`、`Member.__password`、`Member.__borrowed_books` |
| 组合       | `LibrarySystem` 持有 `books`、`members`、`current_member`    |
| 单一职责   | `Book` 管库存，`Member` 管借阅规则，`LibrarySystem` 管交互和持久化 |
| 序列化     | 每个实体都有 `to_dict()`，统一转 JSON                        |
| 数据持久化 | 借书/还书成功后调用 `_save_data()`                           |

## 五、建议的阅读顺序

如果你要自己读代码，建议按这个顺序：

```text
1. main
2. LibrarySystem.__init__
3. LibrarySystem._load_data
4. LibrarySystem.login
5. LibrarySystem.run
6. LibrarySystem.borrow_book
7. Member.borrow_book
8. Book.borrow_book
9. LibrarySystem.return_book
10. Member.return_book
11. Book.return_book
12. LibrarySystem._save_data
```



这样你就能顺着“程序怎么启动 → 怎么登录 → 怎么借书 → 怎么还书 → 怎么保存”完整走一遍。

## 六、一句话总结

这个程序的结构可以记成：

```text
一个入口：
    main

两个核心模型：
    Book、Member

一个继承体系：
    Member -> NormalMember / VIPMember

一个控制器：
    LibrarySystem

两份 JSON 数据：
    books.json、members.json

三条主线：
    数据加载线、用户操作线、数据保存线
```



抓住“**谁持有谁、谁调用谁、数据怎么流动**”，这个代码的结构就清楚了。
